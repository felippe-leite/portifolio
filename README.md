# Felippe Leite — Portfólio

Portfólio pessoal desenvolvido para apresentar minha trajetória profissional, experiências, projetos e conhecimentos em desenvolvimento de software.

O projeto foi construído com foco em **backend e engenharia de software**, utilizando uma interface minimalista, escura e inspirada em conceitos de tecnologia, astronomia e ciência.

## Sobre o projeto

Este portfólio reúne informações sobre minha experiência profissional, formação acadêmica, projetos desenvolvidos, tecnologias utilizadas e áreas que atualmente estou explorando.

A interface foi projetada para ser simples, responsiva e objetiva, priorizando a apresentação do conteúdo técnico sem excesso de elementos visuais.

## Tecnologias

- React
- TypeScript
- Vite
- Tailwind CSS
- HTML5
- CSS3

## Funcionalidades

- Navegação entre as seções do portfólio
- Layout responsivo para desktop e dispositivos móveis
- Apresentação profissional e informações pessoais
- Histórico de experiências
- Formação acadêmica
- Projetos com tecnologias e status
- Links para GitHub e LinkedIn
- Download do currículo
- Formulário de contato
- Envio de mensagens por formulário
- Animações e elementos visuais inspirados em astronomia
- Favicon personalizado

## 💻 Executando localmente

### Pré-requisitos

- Node.js
- npm

### Instalação

Clone o repositório:

```bash
git clone https://github.com/felippe-leite/portifolio.git
```

Entre no diretório:

```bash
cd portifolio
```

Instale as dependências:

```bash
npm install
```

Execute o projeto em ambiente de desenvolvimento:

```bash
npm run dev
```

O Vite disponibilizará a aplicação localmente.

## Build

Para gerar a versão de produção:

```bash
npm run build
```

Para visualizar a build localmente:

```bash
npm run preview
```
